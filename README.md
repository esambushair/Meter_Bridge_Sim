# Meter_Bridge_Sim

The **Meter Bridge Lab** is an interactive virtual physics simulator built with HTML5 Canvas and JavaScript that replicates the classic slide-wire Wheatstone bridge experiment for determining an unknown resistance $X$ directly in the browser. Users control the circuit by closing key $K$, selecting values on a three-decade resistance box ($0\text{–}999\,\Omega$), and sliding or fine-tuning a jockey along a $100\text{ cm}$ resistance wire while tapping it to observe a damped, zero-centre galvanometer ($\pm 30$ divisions). Featuring zoomable views for the circuit schematic, wire magnifier, and galvanometer, along with the ability to interchange gaps $X$ and $R$ to eliminate end-error bias, the app validates null-point readings ($l$) in real time and automatically computes each trial and the overall mean resistance $X$.
